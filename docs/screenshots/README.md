The `design-system` folder holds the browser checks' screenshots, made from invented test data.

**Changing a screenshot.** Replace or add the PNG here and show it in the README; a test fails if a picture in this folder isn't shown there. The privacy guard lets pictures into this folder, but no check looks inside a picture, so look at each one before committing it: only films from a credited open movie library on screen, no folder paths, user, device or card names, and no Steam interface. A film that appears for the first time gets its row in the tables above and in the README.
